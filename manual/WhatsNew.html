What's New in Particles

Release notes for each version of the Particles module. Newest at the top.

Version 1.0.0, FlexSim 2026 (June 17, 2026)

First release. Particles adds placeable, purely visual particle-emitter objects (smoke, steam, dust, sparks, spray) that are drawn analytically at draw time, so they add zero events to the simulation and never slow it down.

  • Emitter and system objects. Drop one or many ParticleEmitter objects; a single ParticleSystem is created automatically and batch-draws every emitter in one pass.
  • Analytic, draw-time particles. Each particle is a closed-form function of model time, so the visuals are frame-skip invariant, deterministic per seed, and free for the simulation engine.
  • Emission region shapes. Point, Line, Disk, Plane, Box, and Sphere, sized by dragging the emitter's own resize handles.
  • Launch control. Aimed (a cone around the aim arrow, with an adjustable Cone Half-Angle) or Omni (all directions), plus initial speed and speed jitter.
  • Closed-form motion. Gravity, wind, exponential drag, and a spiral swirl (amplitude and frequency).
  • Appearance over life. Start and end color with alpha fade, and start and end size.
  • Two render styles. Cheap soft round dots (Points) and textured camera-facing billboards (Sprite) using the emitter's own image.
  • Emission timing. Start and stop time (a number or a FlexScript expression), prewarm so the cloud starts full at reset, and particle lifetime with jitter.
  • System controls. A per-emitter live-particle cap, distance level-of-detail thinning for far emitters, and toggles for the region and aim-arrow handles.
  • Nesting aware. Emitters placed inside other objects emit from their true world position and orientation, at any nesting depth.
  • FlexScript API. Scriptable Particles.System, Particles.Emitter, and the Color, Vec3, Shape, Direction, and Style types, with in-editor autocomplete documentation.
  • In-product help. Quick Properties and System Properties panels, property-panel reference pages, and this manual section.
