Particles.Emitter

Inherits from Object

Description

A placeable particle emitter. Holds the declarative spec (shape, motion, appearance); the singleton Particles.System reads every emitter and batch-draws its particles analytically at draw time, adding zero events to the simulation.

Particles are a closed-form function of model time T (like kinematics), evaluated only when the scene is drawn --so emitters never slow the discrete-event simulation and are frame-skip invariant and deterministic per seedField.

The emission region is sized by the object's own resize handles; particle size is independent of object scale. Drop an emitter and it auto-creates the Particles.System.

Particles.Emitter e = Model.find("ParticleEmitter1");
e.shapeField = Particles.Shape.Sphere;
e.gravity.z = -9.8;
e.startColor = Color.orange;

Units: length = the model length unit, time = the model time unit. Angles are degrees.

Properties

rate Emission rate, particles per time unit. Birth schedule: birth = startTime + i/rate.
startTime Model time at which emission begins (0 = from run start). May be a number OR a FlexScript expression in the property; evaluated each draw.
stopTimeField Model time at which emission ends (0 = never). May be a number OR a FlexScript expression.
prewarm Seconds of pre-simulated emission, so the cloud is already full at reset / T = 0 (evaluates at T + prewarm).
lifetime Particle lifetime in time units.
lifetimeJitter Random per-particle lifetime spread, added as [0, +jitter].
shapeField Emission shape; use Particles.Shape (Point/Line/Disk/Plane/Box/Sphere). The region fills the object's resized footprint.
directionField Launch direction mode; use Particles.Direction (Aimed = cone around the aim arrow / local +Z, Omni = all directions).
coneHalfAngleDeg Spread: the half-angle (degrees) of the Aimed launch cone.
speed Initial launch speed, length per time unit.
speedJitter Random launch-speed spread, applied as +/- jitter.
gravity Constant acceleration (length / time^2). Node-backed: read/write components, e.g. e.gravity.z = -9.8; or assign a whole Vec3.
wind Additional constant acceleration (length / time^2), added to gravity. With drag > 0 it acts as a steady drift toward (gravity+wind)/drag.
drag Exponential velocity-decay rate (1 / time). 0 = none; velocity carries a factor e^(-drag*age).
swirlAmp Radius (length) of a circular wobble added to each particle's path --gives a corkscrew/spiral look. 0 = off.
swirlFreq Angular frequency of the swirl, radians per time unit (period = 2*pi/swirlFreq).
startColor Color (and alpha) at birth. Node-backed: e.startColor.r = 0.5; or e.startColor = Color.red;
endColor Color (and alpha) at end of life. The particle color interpolates startColor -> endColor over its life.
sizeStart Particle size (world diameter) at birth.
sizeEnd Particle size (world diameter) at end of life.
styleField Render style; use Particles.Style (Points = built-in soft dot, Sprite = the object's own image). Every particle is a camera-facing billboard.
seedField Random seed for this emitter (determinism).
statLiveCount Read-only: the number of live particles this emitter drew last frame.
