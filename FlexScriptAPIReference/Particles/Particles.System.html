Particles.System

Inherits from Object

Description

The singleton manager for the Particles module. Discovers every Particles.Emitter in the model and batch-draws all of their particles in one pass at draw time.

Exactly one system exists per model (auto-created when the first emitter is dropped). Access it via the static Particles.system accessor:

Particles.System sys = Particles.system;
sys.liveCap = 50000;
print(sys.statTotalLive);

Holds global render/visibility controls and read-only performance stats. The emitters own their handles and per-emitter spec; the system only draws particles.

Properties

liveCap Hard cap on the number of live particles evaluated per emitter (graceful degradation for heavy scenes).
showPlanes 1 = draw every emitter's region outline (the wireframe shape); 0 = hide.
showArrows 1 = draw every emitter's aim pyramid; 0 = hide.
arrowSize World-unit size of the aim pyramid handle (constant size, independent of emitter scale).
lod 1 = distance LOD on. Far emitters emit fewer particles (the emission rate is scaled by (lodStart/distance)^2 beyond lodStart), cutting draw cost.
lodStart Distance (length units) within which an emitter keeps full detail; beyond it, the LOD rate falloff begins.
lodMin Floor on the LOD multiplier (0-1): how sparse a far emitter is allowed to get. 1 = never thin.
statEmitterCount Read-only: number of emitters found this frame.
statTotalLive Read-only: total live particles drawn this frame across all emitters.
statBuildMs Read-only: milliseconds spent evaluating particles this frame.
statDrawMs Read-only: milliseconds spent drawing particles this frame.
