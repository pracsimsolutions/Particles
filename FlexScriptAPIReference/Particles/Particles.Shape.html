Particles.Shape

Description

An enumeration of the emission region shapes, for shapeField. The region is sized by the emitter object's resize handles.

Model.find("ParticleEmitter1").as(Particles.Emitter).shapeField = Particles.Shape.Sphere;

Properties

Point Emit from a single point.
Line Emit along a line (the object's X extent).
Disk Emit from a filled ellipse in the object's footprint.
Plane Emit from a filled rectangle (the object's footprint).
Box Emit from anywhere within the object's 3D volume.
Sphere Emit from within an ellipsoid volume (naturally omnidirectional; the aim arrow is hidden).
