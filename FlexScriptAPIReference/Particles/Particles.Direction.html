Particles.Direction

Description

An enumeration of the launch-direction modes, for directionField.

Model.find("ParticleEmitter1").as(Particles.Emitter).directionField = Particles.Direction.Omni;

Properties

Aimed Launch in a cone around the aim arrow (local +Z), with the half-angle set by coneHalfAngleDeg.
Omni Launch uniformly in all directions (the aim arrow is hidden).
