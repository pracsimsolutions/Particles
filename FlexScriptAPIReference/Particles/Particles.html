Particles

Description

Visual particle emitters (smoke, sparks, fountains, ...) drawn analytically at draw time so they add zero events to the simulation. Drop a Particles.Emitter from the library; the Particles.System is created automatically.

Particles.System sys = Particles.system;
Particles.Emitter e = Model.find("ParticleEmitter1");

Properties

system The model's single Particles.System (NULL if no emitter has been created yet).
