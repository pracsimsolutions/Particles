Particles.Style

Description

An enumeration of the particle render styles, for styleField. Every particle is a camera-facing billboard regardless of style.

Model.find("ParticleEmitter1").as(Particles.Emitter).styleField = Particles.Style.Sprite;

Properties

Points Render with the built-in soft round dot.
Sprite Render with the emitter object's own image (set it the normal way with the image picker). Falls back to the soft dot if no image is set.
